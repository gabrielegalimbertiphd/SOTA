# SOTA
State-of-the-art navigation system used for navigation test with blind people.

## Running the code:
1. Download the code
2. Open the file "STTN.xcodeproj" with XCode
3. Change the spatial representation in the file "data.json" and insert all the positions of the markers in each path "PercorsoX.json"
4. Run the code
5. Frame the first marker in the path "PercorsoX" (name of the image "initX") and start the navigation towards the destination. The code is set to work from the first turning point.
